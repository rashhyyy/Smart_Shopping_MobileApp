# 📱 Smart Shopping Price Detector

## 🧾 Overview
Smart Shopping Price Detector is a cross-platform mobile application that helps users automatically track shopping expenses in real time. It uses OCR (camera scanning), voice commands, and AI-based discount detection to calculate shopping totals instantly and accurately.

The goal is to eliminate manual price entry, reduce calculation errors, and help users stay within budget while shopping.

---

## 🎯 Problem Statement
Shoppers often face difficulties such as:
- Manual price calculation errors
- Confusion with discounts (e.g., 10% OFF)
- Overspending due to lack of real-time tracking
- No unified system for scanning, voice input, and budgeting

This app solves these problems using automation and mobile AI technologies.

---

## 🚀 Features

### 📷 OCR Price Detection
- Scan product price tags using mobile camera
- Automatically extract prices using OCR

### 🎤 Voice Input
- Add items using voice commands
- Example: "Add 450 rupees"

### 💸 Discount Calculation
- Detect percentage discounts
- Automatically calculate final price

### 🧾 Real-Time Cart
- Live updating shopping cart
- Running total calculation

### 💰 Budget Management
- Set shopping budget
- Alerts when nearing or exceeding limit

### 📊 Shopping History
- Save past shopping sessions
- View previous expenses anytime

---

## 🧠 Tech Stack
- Frontend: React Native  
- Backend: Node.js + Express.js  
- Database: MongoDB  
- OCR: Google ML Kit / Tesseract.js  
- Voice Recognition: Web Speech API / React Native Voice  

---

## 🏗️ Architecture
- Mobile App (React Native)
- OCR Module (Camera-based scanning)
- Voice Module (Speech-to-text)
- Backend API (Node.js + Express)
- Database (MongoDB)
